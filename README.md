# Лабораторная работа №2 — Многопоточность (C++)

## Задание

Заполнить 30000 векторов, содержащих по 100 целых чисел в диапазоне [-1000, 1000].
В отдельных потоках найти сумму элементов для каждого вектора.
Использовать 1, 2 и 4 потока. Найти время исполнения программы в каждом случае.

## Условия выполнения

1. Использовать контейнеры std::vector и std::string.
2. Вывод программы не должен содержать перепутанные части от различных потоков.
3. Измерение времени программы делать без учёта времени заполнения исходных массивов и вывода результатов.
4. Потоки не должны совершать лишние действия.

## Как реализовано

- Данные заполняются одним потоком до старта замера времени.
- Функция computeSums делит диапазон [0, N) на numThreads равных частей.
- Каждый поток обрабатывает только свой диапазон и пишет результат в свою часть массива sums.
- Синхронизация не нужна: потоки не пересекаются по данным.
- Потоки ничего не печатают. Вывод делается из главного потока после join().
- Время измеряется только вокруг вызова computeSums — в микросекундах.

## Сборка и запуск

    clang++ -std=c++17 -O2 -pthread main.cpp -o lab2
    ./lab2

## Пример вывода

    Vectors: 30000, elements per vector: 100

    Threads: 1 | Time: 456 us | Control sum: 437430
    Threads: 2 | Time: 297 us | Control sum: 437430
    Threads: 4 | Time: 268 us | Control sum: 437430

Контрольная сумма одинаковая во всех трёх случаях — значит, результаты корректны.
